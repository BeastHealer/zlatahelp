Создай Telegram-скрипт на Python, используя библиотеку Telethon.

Требования к проекту:

1.Использовать Telethon:
    Client 
    events
    методы получения чатов и сообщений
2.Реализовать функциональность:
    Настройки: api_id, api_hash, session_name
    Подключение к Telegram через Telethon
    Получение списка доступных мне диалогов (чатов)
    Функция для сбора последних N сообщений из выбранного чата
    Автоматическая обработка ошибок и переподключений
    Логирование всех действий
3.Добавь локальную базу SQLite:
    Таблица messages (id, chat_id, sender, text, date)
    Функция save_message() для сохранения сообщения в базу
    Перед вставкой проверять дубли (id сообщения)
4.Добавь асинхронный обработчик:
    На новые сообщения в реальном времени
    Сохраняй их в базу
    Выводи в консоль короткий лог вида:
    [CHAT TITLE] sender: text

5.Структура проекта:
    main.py — основной файл
    db.py — работа с SQLite
    config.py — хранение api_id, api_hash, session_name
    requirements.txt — зависимости

6.Код должен быть:
    Полностью рабочим
    Асинхронным (async/await)
    С комментариями
    Соответствующим лучшим практикам Telethon
7.В main.py добавь пример:
    Получить список чатов
    Собрать последние 100 сообщений из выбранного чата
    Запуск live-слушателя новых сообщений
Сгенерируй полностью готовый проект с соблюдением структуры файлов.
