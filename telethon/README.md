# Telegram Message Collector

Telegram-бот на Python с использованием библиотеки Telethon для сбора и мониторинга сообщений из чатов Telegram.

## Описание проекта

Проект представляет собой асинхронный скрипт, который:
- Подключается к Telegram через Telethon API
- Получает список доступных чатов (диалогов)
- Собирает последние N сообщений из выбранного чата
- Сохраняет все сообщения в локальную базу данных SQLite
- Мониторит новые сообщения в реальном времени
- Автоматически сохраняет новые сообщения в базу данных

## Возможности

✅ **Подключение к Telegram** - безопасное подключение через Telethon с сохранением сессии  
✅ **Получение списка чатов** - просмотр всех доступных диалогов  
✅ **Сбор сообщений** - извлечение последних N сообщений из любого чата  
✅ **Локальная база данных** - SQLite база для хранения всех сообщений  
✅ **Проверка дубликатов** - автоматическая проверка перед сохранением  
✅ **Live-мониторинг** - отслеживание новых сообщений в реальном времени  
✅ **Логирование** - подробное логирование всех действий  
✅ **Обработка ошибок** - автоматическая обработка ошибок и переподключений

## Требования

- Python 3.7 или выше
- Библиотека Telethon
- Аккаунт Telegram
- API credentials (api_id и api_hash) от Telegram

## Установка

### 1. Переход в директорию проекта

```bash
cd telethon
```

### 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение для изоляции зависимостей проекта.

#### Windows

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения
.venv\Scripts\activate
```

#### Linux / macOS

```bash
# Создание виртуального окружения
python3 -m venv .venv

# Активация виртуального окружения
source .venv/bin/activate
```

После активации виртуального окружения в начале строки терминала появится префикс `(.venv)`.

**Деактивация виртуального окружения:**
```bash
deactivate
```

### 3. Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

Или установите Telethon напрямую:

```bash
pip install telethon
```

### 4. Получение API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт Telegram
3. Создайте новое приложение (если еще не создано)
4. Скопируйте `api_id` и `api_hash`

### 5. Настройка конфигурации

Откройте файл `config.py` и укажите ваши данные:

```python
API_ID = 12345678  # Замените на ваш api_id
API_HASH = 'your_api_hash_here'  # Замените на ваш api_hash
SESSION_NAME = 'telegram_session'  # Имя файла сессии (можно оставить как есть)
```

## Запуск

### Первый запуск

1. Убедитесь, что виртуальное окружение активировано (префикс `(.venv)` должен быть виден в терминале)

2. Запустите скрипт:

```bash
python main.py
```

**Примечание:** Если виртуальное окружение активировано, команда `python` автоматически использует интерпретатор из виртуального окружения.

3. При первом запуске вам будет предложено:
   - Ввести номер телефона (в международном формате, например: +79991234567)
   - Ввести код подтверждения из Telegram
   - При необходимости ввести пароль двухфакторной аутентификации

4. После успешной авторизации будет создан файл сессии (`telegram_session.session`), и в следующий раз авторизация не потребуется.

### Что происходит при запуске

1. **Подключение к Telegram** - установка соединения с серверами Telegram
2. **Получение списка чатов** - вывод первых 10 доступных чатов
3. **Сбор сообщений** - автоматический сбор последних 100 сообщений из первого чата
4. **Запуск мониторинга** - активация live-слушателя новых сообщений

## Логирование

Все действия бота логируются в файл `telegram_bot.log` и одновременно выводятся в консоль. Файл логов создается автоматически при первом запуске бота.

### Формат логов

Логи содержат следующую информацию:
- Дата и время события
- Имя модуля
- Уровень логирования (INFO, ERROR, DEBUG)
- Текст сообщения

### Пример записей в логе

```
2024-01-15 10:30:00 - __main__ - INFO - Успешное подключение к Telegram
2024-01-15 10:30:01 - __main__ - INFO - Получение списка доступных чатов...
2024-01-15 10:30:02 - __main__ - INFO - Найден чат: My Chat (ID: 123456789, Тип: Chat)
2024-01-15 10:30:05 - __main__ - INFO - Собрано и сохранено 100 сообщений из чата 'My Chat'
2024-01-15 10:30:10 - __main__ - INFO - Сохранено новое сообщение из 'My Chat' от John Doe
```

**Примечание:** Файл `telegram_bot.log` будет постоянно пополняться новыми записями. При необходимости его можно очистить или архивировать.

## База данных

Все сообщения сохраняются в локальную базу данных SQLite `telegram_messages.db`.

### Структура таблицы `messages`:

| Поле    | Тип    | Описание                    |
|---------|--------|------------------------------|
| id      | INTEGER| ID сообщения (PRIMARY KEY)   |
| chat_id | INTEGER| ID чата                      |
| sender  | TEXT   | Имя отправителя              |
| text    | TEXT   | Текст сообщения              |
| date    | TEXT   | Дата и время (ISO format)    |

### Проверка дубликатов

Перед сохранением каждого сообщения выполняется проверка на дубликаты по комбинации `(id, chat_id)`. Если сообщение уже существует в базе, оно не будет сохранено повторно.

## Настройка сбора сообщений

В файле `main.py` вы можете изменить количество собираемых сообщений:

```python
# В методе run() измените параметр limit:
await self.collect_messages(first_chat_id, limit=100)  # Измените 100 на нужное число
```

## Остановка бота

Для остановки бота нажмите `Ctrl+C` в терминале. Бот корректно завершит работу и отключится от Telegram.

**Важно:** После завершения работы с проектом можно деактивировать виртуальное окружение командой `deactivate`.

## Безопасность

⚠️ **Важно:**
- Никогда не публикуйте файл `telegram_session.session` - он содержит данные для доступа к вашему аккаунту
- Не делитесь `api_id` и `api_hash` с другими людьми
- Добавьте в `.gitignore` следующие файлы/папки, если используете Git:
  - `*.session` - файлы сессий Telegram
  - `.venv/`, `venv/` или `env/` - виртуальное окружение
  - `telegram_messages.db` - база данных (опционально)
  - `config.py` - если содержит реальные credentials (лучше использовать переменные окружения)

## Решение проблем

### Ошибка подключения
- Проверьте правильность `api_id` и `api_hash` в `config.py`
- Убедитесь, что у вас есть интернет-соединение
- Проверьте, не заблокирован ли Telegram в вашей стране/сети

### Ошибка авторизации
- Убедитесь, что номер телефона указан в международном формате (+7...)
- Проверьте правильность кода подтверждения
- Если включена двухфакторная аутентификация, введите пароль

### Сообщения не сохраняются
- Проверьте права доступа к папке (должна быть возможность создания файла БД)
- Убедитесь, что у бота есть доступ к чату (не приватные чаты без добавления бота)
