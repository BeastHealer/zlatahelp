# GigaChat Telegram Bot

Telegram-бот с интеграцией GigaChat API для ответов на вопросы пользователей с помощью искусственного интеллекта.

## Описание

Бот использует GigaChat API для генерации ответов на вопросы пользователей. Просто отправьте боту любой вопрос, и он ответит с помощью AI.

## Возможности

✅ **Интеграция с GigaChat API** - использование искусственного интеллекта для ответов  
✅ **Автоматическое получение токенов** - бот сам получает access token  
✅ **Обработка команд** - /start, /help, /status  
✅ **Умные ответы** - контекстные и информативные ответы на вопросы  
✅ **Логирование** - запись всех действий

## Требования

- Python 3.7 или выше
- Библиотеки: pyTelegramBotAPI, requests, python-dotenv
- Токен бота от @BotFather
- Учетные данные GigaChat API (CLIENT_ID и CLIENT_SECRET)

## Установка

### 1. Переход в директорию проекта

```bash
cd gigachat_bot
```

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

#### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Получение токена Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и скопируйте полученный токен

### 5. Получение учетных данных GigaChat API

1. Зарегистрируйтесь на https://developers.sber.ru/
2. Создайте новое приложение
3. Получите `CLIENT_ID` (используется как RqUID в запросах)
4. Получите `CLIENT_SECRET` (отдельная переменная)
5. Получите `AUTHORIZATION_KEY` (используется для Authorization key в запросах)
   - Это может быть готовый ключ в формате `Basic <encoded_credentials>`
   - Или просто `<encoded_credentials>` (бот добавит префикс `Basic ` автоматически)

### 6. Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

2. Откройте файл `.env` и укажите ваши данные:

```
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
CLIENT_ID=0199ce4a-456d-76aa-8848-06bffe4bf6fa
CLIENT_SECRET=your_client_secret_here
AUTHORIZATION_KEY=Basic MDE5OWNlNGEtNDU2ZC03NmFhLTg4NDgtMDZiZmZlNGJmNmZhOmVhY2MxNzZlLTY0NjUtNDA0OS04Mjc5LTMzNDhiNTAxMDhmMQ==
```

**Примечания:**
- `CLIENT_ID` используется как RqUID (Request Unique ID) в запросах к API
- `CLIENT_SECRET` - отдельная переменная (если требуется)
- `AUTHORIZATION_KEY` используется для Authorization key в запросах
- `AUTHORIZATION_KEY` может быть в формате `Basic <encoded>` (полный формат) или просто `<encoded>` (бот добавит `Basic ` автоматически)

### Первый запуск

```bash
python main.py
```

3. Бот запустится и начнет отвечать на сообщения в Telegram

Нажмите `Ctrl+C` в терминале для остановки бота.

### Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/status` - Проверить статус подключения к GigaChat API

### Примеры использования

1. **Задайте вопрос боту:**
   ```
   Вы: Что такое Python?
   Бот: 💬 Python - это высокоуровневый язык программирования...
   ```

2. **Попросите объяснить что-то:**
   ```
   Вы: Объясни квантовую физику простыми словами
   Бот: 💬 Квантовая физика изучает поведение частиц...

   ```

   ```
   Бот: ✅ Подключение к GigaChat API работает!
   ```

## Логирование

Все действия бота логируются в консоль:
- Команды пользователей
- Запросы к GigaChat API
- Ответы пользователям
- Ошибки

Пример лога:
```
2024-01-15 10:30:00 - INFO - Запуск GigaChat бота...
2024-01-15 10:30:01 - INFO - GigaChat клиент инициализирован
2024-01-15 10:30:05 - INFO - Запрос от 123456789: Что такое Python?
2024-01-15 10:30:10 - INFO - Ответ отправлен пользователю 123456789
```

## Решение проблем

### Ошибка 400 Bad Request при получении токена

Если вы получаете ошибку `400 Client Error: Bad Request`, выполните следующие шаги:

1. **Проверьте формат учетных данных:**
   ```bash
   python test_connection.py
   ```
   Этот скрипт поможет диагностировать проблему.

2. **Убедитесь, что CLIENT_ID и CLIENT_SECRET скопированы полностью:**
   - Они должны быть в формате UUID (например: `0199ce4a-456d-76aa-8848-06bffe4bf6fa`)
   - Не должно быть лишних пробелов в начале или конце
   - Проверьте, что в файле `.env` нет кавычек вокруг значений

3. **Правильный формат файла .env:**
   ```
   CLIENT_ID=0199ce4a-456d-76aa-8848-06bffe4bf6fa
   CLIENT_SECRET=your_client_secret_here
   ```
   ❌ Неправильно: `CLIENT_ID="0199ce4a-456d-76aa-8848-06bffe4bf6fa"`
   ✅ Правильно: `CLIENT_ID=0199ce4a-456d-76aa-8848-06bffe4bf6fa`

4. **Проверьте учетные данные на сайте:**
   - Зайдите на https://developers.sber.ru/
   - Убедитесь, что приложение активно
   - Скопируйте CLIENT_ID и CLIENT_SECRET заново

### Бот не отвечает

- Проверьте правильность `BOT_TOKEN` в файле `.env`
- Убедитесь, что бот запущен
- Проверьте интернет-соединение

### Ошибка "GigaChat клиент не инициализирован"

- Проверьте правильность `CLIENT_ID` и `CLIENT_SECRET` в файле `.env`
- Убедитесь, что файл `.env` находится в директории `gigachat_bot/`
- Проверьте, что учетные данные действительны на https://developers.sber.ru/

### Ошибка при получении токена

- Проверьте правильность `CLIENT_ID` и `CLIENT_SECRET`
- Убедитесь, что ключи скопированы полностью (могут быть длинными)
- Проверьте, что в .env файле нет лишних пробелов вокруг знака `=`
- Убедитесь, что у вас есть доступ к GigaChat API
- Проверьте интернет-соединение
- Используйте `python test_connection.py` для диагностики
