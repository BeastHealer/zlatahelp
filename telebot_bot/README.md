# Telegram Echo Bot

Простой Telegram-бот на Python с функцией echo (повторение сообщений пользователя).

## Описание

Бот повторяет все текстовые сообщения пользователя и реагирует на медиа-файлы (фото, документы, стикеры и т.д.).

## Возможности

✅ **Echo функция** - повторяет все текстовые сообщения  
✅ **Обработка команд** - /start, /help, /echo  
✅ **Обработка медиа** - реакция на фото, документы, стикеры, голосовые сообщения  
✅ **Логирование** - запись всех действий в консоль

## Требования

- Python 3.7 или выше
- Библиотека pyTelegramBotAPI (telebot)
- Токен бота от @BotFather

## Установка

### 1. Переход в директорию проекта

```bash
cd telebot_bot
```

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

#### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Получение токена бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "My Echo Bot")
   - Введите username бота (должен заканчиваться на `bot`, например: `my_echo_bot`)
4. Скопируйте полученный токен (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 5. Настройка конфигурации

Откройте файл `config.py` и укажите ваш токен:

```python
BOT_TOKEN = '123456789:ABCdefGHIjklMNOpqrsTUVwxyz'  # Ваш токен
```

Или отредактируйте `main.py` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен.

## Запуск

### Первый запуск

1. Убедитесь, что виртуальное окружение активировано

2. Запустите бота:

```bash
python main.py
```

3. Бот запустится и начнет отвечать на сообщения в Telegram

### Остановка бота

Нажмите `Ctrl+C` в терминале для остановки бота.

## Использование

### Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/echo <текст>` - Отправить echo сообщение с указанным текстом

### Примеры

1. **Отправьте любое текстовое сообщение** - бот его повторит:
   ```
   Вы: Привет!
   Бот: 📝 Иван, вы написали:
        Привет!
   ```

2. **Используйте команду /echo**:
   ```
   Вы: /echo Тестовое сообщение
   Бот: 🔄 Echo: Тестовое сообщение
   ```

3. **Отправьте медиа-файл** - бот отреагирует:
   ```
   Вы: [отправляете фото]
   Бот: 📷 Иван, вы отправили фото!
   ```

## Логирование

Все действия бота логируются в консоль:
- Команды пользователей
- Echo сообщения
- Медиа-файлы
- Ошибки

Пример лога:
```
2024-01-15 10:30:00 - INFO - Запуск echo-бота...
2024-01-15 10:30:01 - INFO - Пользователь 123456789 (username) использовал команду /start
2024-01-15 10:30:05 - INFO - Echo сообщение от 123456789: Привет!
```

## Решение проблем

### Бот не отвечает

- Проверьте правильность токена в `config.py` или `main.py`
- Убедитесь, что бот запущен (запустите `python main.py`)
- Проверьте интернет-соединение

### Ошибка "Invalid token"

- Убедитесь, что токен скопирован полностью
- Проверьте, что токен не содержит лишних пробелов
- Получите новый токен у @BotFather, если необходимо

### Ошибка при установке зависимостей

- Убедитесь, что используете Python 3.7 или выше
- Попробуйте обновить pip: `pip install --upgrade pip`
- Установите зависимости вручную: `pip install pyTelegramBotAPI`
